# Required practical simulation sheets

One printable A4 sheet per AQA GCSE Physics required practical, for doing the practical with the Practical Lab
simulations. Each has an aim, short checklist steps naming the on-screen controls, results tables, graph paper and
questions. The Combined Science practical number is shown where there is one.

Edit the content in `tools/practical_sheets.py`, then rebuild:

```
python3 tools/practical_sheets.py && node tools/practical_sheets_pdf.cjs
```
